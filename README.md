# Personal Portfolio

Welcome to my personal portfolio!

This project is part of my Internet Programming I course. It is developed using HTML5 and demonstrates the fundamental concepts of HTML learned throughout Chapter 2 (Part I).

## About Me

I am a Software Engineering student interested in technology, programming, and continuous learning. This portfolio introduces my background, skills, education, and projects.

## Project Objectives

- Practice writing basic HTML documents.
- Understand HTML elements and attributes.
- Create hyperlinks and page navigation.
- Work with images, lists, and tables.
- Build a simple two-page personal portfolio.

## Pages

- index.html – Main portfolio page containing my introduction, skills, education, and contact information.
- projects.html – A dedicated page showcasing my projects.
